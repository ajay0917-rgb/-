# 燼符行 EMBERWRIT

三道戰場的符籙肉鴿（roguelite）構築卡牌遊戲。純 HTML／CSS／JavaScript，不需要安裝或建置。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可。進度自動存在瀏覽器的 localStorage，關掉再開可以「繼續旅程」。

遊戲內的「玩法說明」與「設計源流」有完整規則，以及每個機制取自哪款遊戲、修正了哪個缺點。

## 核心玩法

- **三道戰場**：左、中、右三道，你站在其中一道。與敵人同道（正對）時攻擊倍率 +0.5，但也最容易挨打。
- **敵人意圖會標明打哪一道**：瞄準（移開就落空）、正面、橫掃、追蹤。每道直接顯示本回合會吃多少傷害。
- **友軍**：召喚到道上，回合結束時攻擊同道敵人，並替你擋下該道的攻擊。死亡留下骨，用來支付骨費卡牌。
- **傷害公式**：（基礎 + 加值）× 倍率。滑鼠移到攻擊牌上，每名敵人都會預覽實際傷害與計算過程。
- **主副雙派系**：赤焰、玄霜、骸契、雷樞四選二，同回合打出 3 張同派系牌觸發共鳴。
- **護符**：有序、限 5 欄、可出售、可調順序（鏡像符複製右側那個）。
- **印記**：刻在牌上的額外能力，祭壇可以刻印或轉印。
- **燭火**：戰敗時熄滅一根，以 50% 生命重打同一場戰鬥。
- **燼階**：通關後解鎖更高難度（0–5）。

## 快捷鍵

| 按鍵 | 作用 |
| --- | --- |
| 1–0 | 選牌 |
| 1／2／3 | 選好需要目標的牌後，指定左／中／右 |
| A／D、←／→ | 移動 |
| E、空白鍵 | 結束回合 |
| R | 重整（棄牌再抽） |
| Esc、右鍵 | 取消 |

## 檔案結構

```
index.html          進入點
css/style.css       全部樣式
js/core.js          亂數、工具、派系、狀態、印記、關鍵字
js/data_cards.js    卡牌（約 80 張）
js/data_charms.js   護符、能力、英雄晉升、消耗品
js/data_enemies.js  敵人、遭遇表、各幕強度倍率（ENEMY_SCALE）
js/data_events.js   事件與古神祝福
js/combat.js        戰鬥引擎
js/run.js           跑圖、地圖生成、獎勵、商店、存檔
js/ui.js            所有畫面與特效
js/main.js          啟動
```

想調整難度，先改 `js/data_enemies.js` 開頭的 `ENEMY_SCALE`（各幕敵人生命與攻擊倍率）。

## 美術

- 清單與提示詞：`art/美術清單.md`、`art/ChatGPT提示词.md`、`art/prompts.csv`
- 生好的圖照編號存進 `art/inbox`（例如 `045.png`），再在專案資料夾執行：

```
python art/tools/build_art.py
```

腳本會把圖轉成 WebP 放到對應資料夾（`art/enemies/crow.webp` 等）、把四格圖切開，並更新 `js/art_manifest.js`。遊戲只顯示清單裡有的圖，其餘位置繼續用單字印章。需要 Pillow：`python -m pip install pillow`。

小頭像的取景（臉的位置、放大倍數）寫在 `art/tools/focus.json`。
